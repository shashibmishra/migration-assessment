# Terraform modules for AKS platform

This folder contains reusable Terraform module stubs for provisioning AKS platform components.

Modules included (stubs):
- `modules/aks` — AKS cluster
- `modules/acr` — Azure Container Registry
- `modules/log-analytics` — Log Analytics workspace
- `modules/keyvault` — Key Vault and secrets

This directory is a starting point — replace placeholders and add provider/auth configuration before running.
